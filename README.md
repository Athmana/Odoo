# Brightloop Software — Unified Subscription Management & Recurring Billing Platform

Brightloop Software is an enterprise subscription lifecycle and recurring billing platform that automates product catalogs, multi-interval plans, quotations, recurring invoices, tax rules, conditional discounts, payment reconciliation, and real-time revenue intelligence.

---

## Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Initialize database & seed sample data
npm run setup

# 3. Start the server
npm run dev
```

Open **[http://localhost:3000](http://localhost:3000)** in your browser.
